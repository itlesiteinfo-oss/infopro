# Horizon Press News Bar — Implementation contract (V1.0.0)

This document is the binding technical contract derived from the cahier des charges
(`docs/cahier-des-charges.md`). Every implementer (human or agent) must follow it exactly:
class/method names, signatures, option keys, HTML markup, CSS classes, data attributes and
JS behaviours below are fixed. Where the cahier des charges is more specific, it wins.

Language: code comments, docblocks and source strings are **English**. French is provided
through `languages/horizon-press-news-bar-fr_FR.po/.mo`.

## 0. Absolute rules (from the spec)

- No SaaS, no outbound network call, no telemetry, no JS framework, no jQuery added by the
  plugin, no CDN, no external font, no custom SQL table, no cron, no `eval()`, no `extract()`,
  no `$_REQUEST`, no dynamically generated code, no `ORDER BY RAND()`, no cache-plugin
  detection, no arbitrary CSS field, no CPT, no Gutenberg block.
- `get_option( 'hprnb_settings' )` is only allowed inside `class-settings.php`.
- Autoload parameters passed to `add_option()` / `update_option()` are **booleans**.
- No translation function may run before the `init` hook.
- Every executable PHP file starts with an `ABSPATH` guard (`defined( 'ABSPATH' ) || exit;`).
- `wp_is_mobile()` is never used. Device visibility is CSS only (768px fixed breakpoint).
- Contract with the theme and other plugins (v2): `--hprnb-offset` on `<body>` (visible height: 40 desktop, 76 / 40 mobile, 0 while hidden), `body.hprnb-is-collapsed`, `body.hprnb-kbd`, `body.hprnb-theme-offset`, `document` event `hprnb:state` with `{ mobile, collapsed, height, offset }`, `window.hprnbBar.state()`, and `body.hprnb-pending` while the bar waits for its reveal threshold (2.3: `--hprnb-offset` is then 0 and no space is reserved). A profile placed inside the article, and a bar collapsed from 768px, also report an offset of 0 (2.4). Nothing foreign is ever inserted in the bar.
- Escaping at output: `esc_html()`, `esc_attr()`, `esc_url()`; colours validated with
  `sanitize_hex_color()` at input; IDs with `absint()`.
- No `console.log` in production JS. All `localStorage`/`sessionStorage` access in `try/catch`.
- WordPress Coding Standards (tabs, Yoda conditions, spacing) — the repo runs PHPCS `WordPress`.
- Text domain: `horizon-press-news-bar`. Use `__()`, `esc_html__()`, `esc_attr__()`, `_n()`,
  `_x()`, numbered placeholders in `sprintf` when more than one, no string concatenation of
  sentences.

## 2. Settings (`class-settings.php`, class `Settings`)

```php
const OPTION         = 'hprnb_settings';
const EPOCH_OPTION   = 'hprnb_cache_epoch';
const SCHEMA_OPTION  = 'hprnb_schema_version';

public static function schema(): array;        // key => descriptor (see below)
public static function defaults(): array;      // from schema, schema order
public static function get(): array;           // memoised per request; sanitize(stored, defaults) then apply_filters( 'hprnb_settings', $settings )
public static function raw(): array;           // stored option without filter (sanitized); used by admin form + export
public static function sanitize( $input, ?array $base = null ): array;   // THE validator. $base defaults to defaults(). Unknown keys ignored. Missing keys => $base value.
public static function sanitize_form( $input ): array;   // same but missing bool => false, missing id_list => [], missing bool_map entries => false (HTML form semantics). Used by register_setting sanitize callback and by the preview endpoint.
public static function update( array $clean ): bool;     // update_option( OPTION, $clean, true ); flushes memo
public static function reset(): void;                    // update( defaults() )
public static function flush(): void;                    // clear per-request memo
public static function window_bounds(): array;           // [ 'minutes' => [1,1440], 'hours' => [1,720], 'days' => [1,30] ]
public static function uninstall_delete_requested(): bool; // reads raw option
```

Descriptor shape: `[ 'type' => ..., 'default' => ..., + type-specific keys ]`.
Types and sanitizers:

| type | descriptor keys | sanitizer |
|---|---|---|
| `bool` | — | `rest_sanitize_boolean()` semantics: true/'1'/'true'/'on'/1 → true |
| `int` | `min`, `max` | `(int)`, clamp to [min,max]; non-numeric → default |
| `text` | `max_length`, `allow_empty` (bool, default true) | `sanitize_text_field()`, `mb_substr( 0, max_length )`; empty & !allow_empty → default |
| `key` | — | `sanitize_key()`; empty → default |
| `color` | — | `sanitize_hex_color()`; invalid → default |
| `enum` | `options` (list) | in list → value; else default |
| `id_list` | — | `wp_parse_id_list()` then `array_filter( >0 )`, `array_values`, unique, max 500 entries |
| `bool_map` | `keys` (list) | assoc array of listed keys → bool (missing → default of that key in `sanitize`, false in `sanitize_form`) |

Cross-field rule: `window_value` is clamped to the bounds of the sanitized `window_unit`.

### Root attributes and events added in 2.5

- `data-hprnb-count` — the number of headlines rendered. The stylesheet reads it (a single headline never carries a separator, alongside `:only-child`) and so do the analytics. The hybrid bootstrap keeps it in sync on a REST refresh and in its sessionStorage copy.
- `data-hprnb-post` — the singular object being viewed, or 0.
- `data-hprnb-id` on each `.hprnb-bar__item` — the recommended article.
- `--hprnb-m-gap` — the distance a floating mobile layout keeps from the bottom edge (8px for the "discover" card, 0 elsewhere). Written on the root, on the body by PHP, and copied by the bootstrap. The body reserve and `--hprnb-offset` add it; the card carries the safe area itself so it is never counted twice.
- Analytics, opt-in by nature and never required: `hprnb_impression`, `hprnb_click`, `hprnb_close` pushed on `window.dataLayer` when one exists AND dispatched on `document` as `hprnb:hprnb_impression` and so on. No network call is ever made — the plugin's "no telemetry" rule stands: nothing leaves the page unless the site's own tag manager chooses to send it.

## 5. Cache (`class-cache.php`, class `Cache`)

```php
const KEY_PREFIX = 'hprnb_bar_';
const PAYLOAD_KEYS = [ 'label_text','label_position','window_value','window_unit','categories_include','categories_exclude','tags_include','content_exclude_post_ids','max_items','orderby','layout_mode','show_relative_time','relative_time_max_hours','show_thumbnail','thumbnail_size','ticker_enabled','ticker_mode','ticker_speed','rotate_interval','pause_on_hover','close_button','remember_dismiss','dismiss_duration_hours' ];

public static function epoch(): string;                       // get_option( EPOCH_OPTION ); creates one (wp_generate_uuid4(), autoload true) if missing/invalid
public static function hash( array $settings ): string;       // md5( wp_json_encode( [ subset of PAYLOAD_KEYS in fixed order, determine_locale(), HPRNB_VERSION ] ) )
public static function key( array $settings ): string;        // KEY_PREFIX . epoch() . '_' . hash()
public static function ttl( array $settings ): int;           // (int) apply_filters( 'hprnb_cache_ttl', $settings['cache_ttl'], $settings ), clamped [30,600]
public static function get( array $settings ): ?array;        // get_transient(); returns null unless is_valid()
public static function set( array $settings, array $payload ): void; // set_transient( key, payload, ttl )
public static function is_valid( $payload ): bool;            // array with version === HPRNB_VERSION, int generated_at, int count, array items, string html
```

Colours, sizes, z-index and the separator settings (`show_separator`, `separator_char`, `separator_after_last`) are **not** part of the hash: they are CSS variables / classes on the root, assembled outside the cache.

Payload shape (also the REST body minus `items`):

```php
array( 'version' => HPRNB_VERSION, 'generated_at' => time(), 'count' => 7, 'items' => [...], 'html' => '<aside ...>...</aside>' ) // html '' when count 0
```

## 7. Invalidation (`class-invalidation.php`, class `Invalidation`)

```php
public static function register(): void;
public static function invalidate(): void;   // static guard: once per PHP request. update_option( 'hprnb_cache_epoch', wp_generate_uuid4(), true ); Payload::flush(); do_action( 'hprnb_cache_invalidated' )
public static function reset_guard(): void;  // tests only
```

Hooks (all callbacks tolerant to any argument types, post type `post` only where relevant):

- `transition_post_status( $new, $old, $post )` → invalidate when post type is `post` and ( `$new === 'publish'` or `$old === 'publish'` ).
- `deleted_post( $post_id, $post )` → post type `post`.
- `set_object_terms( $object_id, $terms, $tt_ids, $taxonomy, ... )` → taxonomy `category`/`post_tag` on a `post` with status `publish`.
- `delete_term( $term, $tt_id, $taxonomy )` → taxonomy `category`/`post_tag`.
- `added_post_meta` / `updated_post_meta` / `deleted_post_meta` with `$meta_key === '_thumbnail_id'` on a `post`.
- `update_option_hprnb_settings` and `add_option_hprnb_settings` → invalidate + `Settings::flush()`.
- `switch_theme` → invalidate.
- Import / reset / deactivation call `Invalidation::invalidate()` directly.

Never scan `wp_options` to delete old transients.

## 12. REST (`class-rest-controller.php`, class `Rest_Controller`)

Route `GET /hprnb/v1/items`, `permission_callback => '__return_true'`, no args.

Response body: `{ "version": "1.0.0", "generated_at": 1757600000, "count": 7, "html": "<aside ...>" }`
(`items` is not sent). When count 0: `{ "version": "1.0.0", "generated_at": ..., "count": 0, "html": "" }`.
When the plugin is disabled (`enabled` false): count 0, html ''. Uses `Payload::get()` — same
cache and renderer as SSR. Reads no cookie, starts no session, ignores the current user.

Headers on this response only: `Cache-Control: public, max-age=60, s-maxage=60, stale-while-revalidate=120`,
`ETag: "<md5 of version|generated_at|count|html>"`, `Last-Modified: <gmdate RFC 7231 of generated_at>`.
If `If-None-Match` (after trimming an optional `W/` prefix) equals the ETag → status 304, empty body
(implemented locally: return `WP_REST_Response( null, 304 )` and add a `rest_pre_serve_request`
filter *inside the callback* that sends the headers and returns `true` so no body is echoed).
Never add a permanent global filter on `rest_send_nocache_headers`.

### 14.2 `hprnb-bootstrap.js` (IIFE, ≤ 3 KB minified) — hybrid freshness algorithm

### 14.3 `hprnb-bar.js` (IIFE, ≤ 10 KB minified) — interactive features

Exposes `window.hprnbBar = { init: function(root) }`; on load calls `init(document.getElementById('hprnb-root'))`.
`init` is idempotent per aside (`aside.dataset.hprnbInit === '1'` → return). Reads config from
the aside `data-hprnb-*` attributes. Features:

- **Relative time** (`data-hprnb-reltime="1"`): every 60 s update each `time[data-hprnb-ts]`
  text with `Intl.RelativeTimeFormat(document.documentElement.lang || 'en', {numeric:'auto'})`
  (units: second→minute→hour→day) when age < reltime-max hours, else set text to `data-hprnb-abs`.
  Timer suspended when `document.hidden`, resumed (with immediate refresh) on visible. If
  `Intl.RelativeTimeFormat` is unavailable, leave the server text.
- **Close** (`.hprnb-bar__btn--close`): hide the aside (`aside.hidden = true`, root
  `hidden`), remove `body.hprnb-reserve`, if `data-hprnb-remember="1"` write
  `localStorage.hprnb_dismissed_until = Date.now() + hours*3600e3` (try/catch). Focus
  management: before hiding, move focus to `document.querySelector('main, [role=main]') ||
  document.body`; if that element is not focusable add `tabindex="-1"` temporarily, call
  `focus({preventScroll:true})`, then remove the temporary tabindex.
- **Reduced motion**: `matchMedia('(prefers-reduced-motion: reduce)').matches` → marquee and
  rotate are not started: the bar behaves as static (marquee) or as manual (rotate → show all
  items, hide toggle button). Also add class `hprnb-bar--reduced`.
- **Marquee** (`data-hprnb-ticker="marquee"`): wrap the `ul` in `<div class="hprnb-bar__track">`,
  measure `list.scrollWidth` vs `viewport.clientWidth`; if it fits → no clone, no animation,
  toggle button `hidden`. Else append a clone of the `ul` (`aria-hidden="true"`, class
  `hprnb-bar__list hprnb-bar__list--clone`, every `a` gets `tabindex="-1"`), set
  `--hprnb-track: <listWidth+gap>px` and `--hprnb-duration: <trackPx / speed>s` on the track,
  add `hprnb-bar--marquee-on` on the aside; direction from `getComputedStyle(aside).direction`
  → add `hprnb-bar--rtl` when rtl (CSS uses a different keyframe). Recompute on
  `ResizeObserver` of the viewport (fallback: debounced `resize` 200 ms). Pause = class
  `hprnb-bar--paused` (CSS `animation-play-state: paused`): on `document.hidden`, on focus
  inside the list (`focusin`/`focusout`), on hover when `data-hprnb-hover="1"`, and via the
  toggle button (sticky user pause: hover/focus resume never overrides a user pause).
- **Rotate** (`data-hprnb-ticker="rotate"`): one `li` visible, others `hidden`; advance every
  `data-hprnb-interval` ms with `setTimeout` chaining (no rapid loop). Pause on `document.hidden`,
  on focus inside, on hover when enabled, via toggle button. Single item → no timer, hide toggle.
- **Manual** (`data-hprnb-ticker="manual"`): prev/next buttons scroll the viewport by
  `viewport.clientWidth * 0.8` (`scrollBy({left, behavior:'smooth'})`, reversed sign in RTL);
  buttons disabled at the ends (update on `scroll` and resize, using a 2 px tolerance);
  both disabled when content fits.
- **Toggle button**: updates `aria-label` from `data-hprnb-label-pause` / `data-hprnb-label-play`
  and toggles `hprnb-bar--paused`.
- Page Visibility API for every timer/animation. No `setInterval` moving pixels. No `console.log`.

## 21. Paragraph trigger and "follows the reading" collapse (2.7.0)
